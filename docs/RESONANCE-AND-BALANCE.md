# 0.7：重複招募成長與五種守護路線

## 設計目的

讓重複史詩／傳說同時帶來「這隻變強」與「朝指定收藏前進」兩種進展。
保持首次取得即可完整操作角色；沒有把原有招式鎖在重複抽取後面。
所有守護路線都使用已有的本地動畫與真實招式執行器，沒有新增素材下載依賴。

參考的是機制，而非複製他作程式或資產：

- [Pokémon Masters EX 官方更新](https://pokemonmasters-game.com/en-US/announcements/Update_2040_1W_1)：重複拍組提升招式等級，滿級後轉為潛能提升道具。
- [HoYoverse 官方說明](https://support.hoyoverse.com/hc/en-us/articles/52089402385945-What-rewards-do-I-get-for-obtaining-a-duplicate-character-near-or-at-C6)：重複角色提供命之座材料與星輝，滿階後提供其他回饋。
- 本版採自己的 +5 上限與精華價格，不照搬商業轉蛋的付費設計。本遊戲招募券仍由遊玩取得。

## 共鳴規則

| 事件 | 成長 | 精華 | 金幣 |
| --- | --- | --- | --- |
| 首次取得物種 | +0，加入收藏 | 0 | 原規則 |
| 重複史詩，尚未 +5 | +1 階 | 1 | 原本的 120（重複異色 360） |
| 重複傳說，尚未 +5 | +1 階 | 3 | 原本的 300（重複異色 900） |
| 已 +5 史詩再次重複 | 維持 +5 | 3 | 保留 |
| 已 +5 傳說再次重複 | 維持 +5 | 9 | 保留 |

普通與異色共用物種階級。已擁有普通版時，第一次抽到異色仍解鎖異色，同時提升共鳴；
這個首次異色沒有原版「重複異色金幣」，不將它誤算為三倍金幣。
同一次十連裡的重複逐隻入帳，結果卡保存每次的前後階級。

- 每階攻擊 +4%、起始生命 +3%，+5 時分別 +20%、+15%。
- +3 額外將招式冷卻乘 0.95；+5 額外移速 +5%。
- 這是操控角色的物種成長，經典／遠征／守護模式出戰都適用。
- 守護寵物原本以操控角色攻擊為基礎；不再重套一次寵物自身的共鳴，避免乘算兩次。
- 共鳴與全隊金幣強化、遠征熟練度是不同系統，原進度保留。

工坊位於「招募夥伴」機率說明下方，也可在已擁有角色的圖鑑詳情直接培養。

| 用途 | 史詩精華費用 | 傳說精華費用 |
| --- | ---: | ---: |
| 指定已擁有角色提升一階 | 12 | 36 |
| 招募未擁有物種（普通版 +0） | 40 | 120 |

兌換不影響招募保底、不消耗招募券，也不會產生金幣或精華返還循環。
原 70 抽傳說保底、十連至少史詩與機率不變。非法數量、世代或付款方式不扣券。

## 守護路線

| 路線 | 完全體所需守護秒數 | 定位與差異 |
| --- | ---: | --- |
| 小火龍→火恐龍→噴火龍 | 205 | 延長火焰飛行時間 65%、扇形 0.9→0.72；助戰威力 3.4→3.8、間隔 1.15→1.05 秒。強化近中距離火力。 |
| 綠毛蟲→鐵甲蛹→巴大蝶 | 175 | 保留最快成長與追蹤減速；治療由每 12 秒玩家 7%／寵物 12%，改每 10 秒 9%／15%，限靠近 220 範圍。 |
| 鯉魚王→暴鯉龍 | 240 | 保留最長守護換取高壓水炮與震退浪潮；數值不變，補計浪潮傷害統計與命中回呼。 |
| 皮丘→皮卡丘→雷丘（新增） | 195 | 六目標連鎖十萬伏特、減速；10 秒一次近身放電與擊退，擅長分散敵群。追獵者為頓甲。 |
| 小山豬→長毛豬→象牙豬（新增） | 220 | 冰凍光束貫穿減速；12 秒一次震退粉雪，附近玩家護盾補至生命 12%、寵物補至 15%，不堆疊、不覆蓋更高護盾。追獵者為鴨嘴炎獸。 |

五條路線共用原本的幼體守護、進化、救援、召回、追獵者、收藏與一次性結算流程。
新增第四、第五選項可點選，也可按數字鍵 4、5。

## 量測證據與限制

基線來源提交：`c87d4972776f9b7064813040972a8ab0f1dedad0`。
`node tools/measure-guardians.mjs` 在 60 Hz 模擬 30 秒，使用真實寵物、招式、投射物與碰撞程式。
操控者攻擊固定 1、無強化、寵物位置固定、一般屬性無限血靶、開放地形。
不模擬灼傷持續跳傷、擊退移動、敵人反擊或玩家走位；以下是直接傷害 DPS，不是勝率或完整排名。

| 完全體 | 舊版距離 100／180／250 | 新版距離 100／180／250 | 新版扇形五靶 | 新版直線五靶 |

因此優先修正噴火龍的射程落差，巴大蝶增加支援價值，暴鯉龍保留長成長時間的爆發回報。
初查所見 380 是索敵距離，攻擊執行器另有射程檢查；真正的問題是短火焰壽命與散射讓邊緣命中率急降，
並不是所有 380 內敵人都能觸發空放。新雷丘偏群控、新象牙豬偏保護，不追求每種情境 DPS 相同。

## 存檔與驗證

延用 `ps.save.solo` 與原 JSON 備份格式；新增 `resonance: { ranks, essence }`。
舊存檔補空欄位、保留金幣、角色、強化與任務；沒有逐物種歷史重複次數，無法可靠追溯補發。
合併取較高階級，精華取較新存檔，避免已花資源復活。匯入拒絕負值、非整數、超過上限或無效物種。

驗證指令：

```sh
node tools/check-resonance.mjs
node tools/check-expedition.mjs
node tools/measure-guardians.mjs
node tools/build-solo.mjs
node --check dist/js/game.bundle.js
```

本次環境沒有 Sites 指定的 browser-control，不做瀏覽器、iPhone 觸控或完整通關驗收。
測試僅用隔離記憶體存檔，不會讀寫玩家目前的瀏覽器進度。
