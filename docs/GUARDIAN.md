# 守護夥伴模式（0.5）

本模式加在現有單人遠征之上，使用相同地圖、敵人、遺物、委託、永久強化與大絕。
在營地出發前選「守護夥伴」。所有模型和招式資源都來自專案原有的本機資產。

## 遊玩循環

1. 本局非裂隙時間到 60 秒，玩家附近出現金色守護寶箱。左上顯示方位；走近停留 3 秒開啟。
2. 暫停戰鬥，三選一救出幼體。幼體／中間階段跟隨、不攻擊，需要玩家保護。
3. 夥伴存活且距玩家小於 220 遊戲單位時累積成長，進化後回滿生命。時間為從救出後累計。
4. 完全體自動助戰。享受 30 秒戰力提升後，等待既有首領被擊倒，再以 8 秒預警出現追獵者。
5. 追獵者半血狂怒，加快移動與地面預警頻率；預警攻擊玩家、夥伴腳下，狂怒後增加一個前方點。
6. 擊倒追獵者，且夥伴存活，便發放一次獎勵並可結伴回營。若夥伴倒下，先救援再領獎。

## 保護與救援

- 部分附近普通敵人會追逐夥伴；敵方子彈與地面危險同樣能傷到牠。
- 玩家距離 100 內，夥伴所受傷害再乘 0.5；更遠為 0.85。另計屬性與永久減傷。
- 夥伴受擊後有 0.8 秒保護；靠近時每秒回復 0.3% 最大生命及永久回復量。
- G／左上「召回」：帶回身邊安全位置，活著時回復 18% 生命與 1.5 秒保護；冷卻 14 秒。
- 倒下仍可召回。玩家靠近守住 3 秒，回復 60% 生命並有 3 秒保護。離開時救援進度逐步下降。
- 倒下、離得太遠、進入裂隙時不成長；裂隙時整個守護計時暫停，返回後夥伴在玩家身邊重新跟隨。
- 跟隨使用既有尋路與碰撞，卡住或落後太遠時回到附近安全位置，避免永久遺失。

## 回報、存檔與相容性

擊敗追獵者且救回夥伴，整條進化系加入永久收藏，發放 250 基礎金幣（結算套用本局倍率）及 3 張招募券。
本局只發一次；可以繼續原遠征，包含 12:00 首領的獨立獎勵。守護勝利後暫緩排程首領 20 秒。
永久統計 `guardianBonds` 和 `guardianBond_flame/wings/tide` 隨既有 JSON 備份保存。
夥伴本身及其成長屬於本局；目前不支援關閉頁面後恢復未結束戰鬥，與原版本相同。
不更換 localStorage 名稱、不遷移既有收藏、不修改永久強化的共用規則。

## 修改入口

- `js/systems/guardian.js`：LINES、成長、救援、助戰、追獵與一次性獎勵。
- `js/systems/guardian-steering.js`：Yuka ArriveBehavior 的二維改編，搭配遊戲碰撞。
- `js/ui/guardian-ui.js`：進化選卡、HUD、召回按鈕與結算。
- `js/ui/expedition-ui.js`：模式入口；`expedition.js`：每局生命週期。
- `enemy.js` / `combat.js` / `hazards.js`：NPC 目標與傷害；`spawner.js`：首領生成及避免重疊。
- 執行 `node tools/build-solo.mjs` 重建 `dist/`。程式與素材授權見 CREDITS.md、LICENSE、assets/licenses/YUKA-MIT.txt。
